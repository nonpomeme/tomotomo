## 3. 不足している箇所

### 章の不足
| 章 | 状態 | 足りないもの |
|---|---|---|
| ① 組織の目的と人材要件 | △ | 事業戦略から人員計画・人材要件（職務記述・コンピテンシー）を導く方法、要員計画の手法 |
| ② 採用計画と母集団形成 | ○（偏りあり） | 求人票の法令・スカウトは厚い。採用ブランディング（EVP）、候補者体験、チャネル別の歩留まりとKPI設計が薄い |
| ③ 選考 | **×** | 構造化面接、適性検査、ワークサンプル、選考手法の予測力（妥当性）の研究がまったくない。AI選考の説明責任の1問のみ |
| ④ オンボーディング | **×** | 用語の1問のみ。受け入れ設計、早期離職、戦力化までの期間の研究がない |
| ⑤ チームづくり | △ | 権限委譲の1テーマのみ。心理的安全性、チームの成果要因の研究がない |
| ⑥ 評価と育成 | **×** | フィードバック、1on1、評価制度、研修設計（効果測定）がない |
| ⑦ エンゲージメントと定着 | **×** | 離職の要因と防ぎ方、エンゲージメントの測り方がない |
| 補章 採用業界の構造 | △ | 人材紹介・求人広告・ダイレクトリクルーティング・RPO・採用コンサルのビジネスモデルとお金の流れを体系的に扱った教材がない（専門知識の一覧に題材はあるが、10/26 は調査段階で失敗） |

### 視点の不足
- **お客さん視点**：ケース問題と「立場別の使い方」で全体に入っている（最も充実）。ただし「コンサルが見落としがちな点」を明示した箇所はない
- **教える視点**：**ほぼない**。研修のワーク・ケースの使い方・確認問題の使い方として書かれた箇所がない（データの読み方の問題2問が近い程度）
- **仕組みの視点**：**AIを主題にした2テーマのみ**。各段階で「どの作業をAI・システムで改善できるか」「どんなデータが扱われているか」が書かれていない

### テンプレート（設計書3章）の不足
| 項目 | 状態 |
|---|---|
| 1. 位置づけと前後の章とのつながり | なし（教材は日付順の単発で、章の概念がない） |
| 2. 核心概念 | 部分的（3分の解説・キーワード） |
| 3. 根拠と信頼度 | **なし**。ランクの表示がない。サンプルの出典は組織のトップページのみで、根拠を特定できない。配信教材の多くは企業のプレスリリース（C） |
| 4. お客さん視点 | あり |
| 5. 教える視点 | なし |
| 6. 仕組みの視点 | ほぼなし |
| 7. 最新トレンド | 毎日の配信が実質トレンドだが、根拠の章と分けて扱われていない |
| 8. 出典一覧 | テーマ単位のみ。問題・解説ごとの出典はない |

### 方針の食い違い（要確認）
- 今の毎日の配信は、10/20 の変更で **7分野（採用・人材／産業／法律／経済／経営／テクノロジー／社会）** を扱う設定になっている。設計書は **採用・組織づくりのライフサイクル7章＋補章** に絞る方針で、食い違っている（10/12 の包装リサイクルなど、×の教材が出る原因でもある）
- 設計書は「トレンドはC以下になりやすいので、根拠の章と分けて扱う」としている。今の毎日の配信は、企業のプレスリリース（C）を中心に教材を作っている

### 既存の不具合（あわせて直す）
- 10/24 以降、調査段階で事実がほぼ捨てられ（「確かめた事実が4件未満」）、5日で1件しか配信できていない。開いたページのURLの照合が厳しすぎること（末尾のスラッシュ・転送先の違い）と、最終回答の取り出し方が原因と見られる
